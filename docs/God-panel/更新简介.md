# 创意工坊简介 · 更新手册与模板

本文只用于**更新 Steam 创意工坊简介**，是操作手册与可复制模板，不是简介正文。

- 简介正文（发布时实际粘贴的内容）：同目录 `创意工坊简介.md`，只读参考。
- 更新素材来源：`Universal tool\文档\更新公告.md`（面向玩家的版本变化）。
- 物品名核对来源：`Universal tool\文档\物品清单.md`。

使用方式：先按「更新流程」确定要改哪些区块，再从「BBCode 标签速查表」确认写法，最后用「完整模板」替换正文。

---

## 更新流程

### 1. 确定是否要更新

出现以下任一情况时更新简介：

- 发布新版本；
- 修复了玩家可见的重要 bug；
- 新增、改名或移除了物品/功能；
- 已知问题状态发生变化（例如某项功能通过了游戏内验证）。

### 2. 取素材

- 从 `Universal tool\文档\更新公告.md` 取最新版本的变化，提炼出**玩家可见**的部分：新增了什么、改了什么、移除了什么。
- 从 `Universal tool\文档\物品清单.md` 核对物品的准确名称（例如「输入器」还是「输入终端」）。
- 只搬运结论，不要把开发过程、反编译结论、待决策事项写进简介。

### 3. 修改模板中的对应区块

| 发生了什么 | 改哪个区块 |
|---|---|
| 发布新版本 | 「更新公告」区：在顶部新增一条版本条目 |
| 新增/移除物品，或功能定位变化 | 「主要内容」区：增删条目 |
| 新增未验证功能，或功能通过验证 | 「已知问题」区：加入或移除对应条目 |
| 阶段目标变化 | 「后续计划」区：调整条目 |
| 玩法循环或定位变化 | 「模组简介」区 |

### 4. 发布前检查清单

- [ ] BBCode 标签全部闭合（`[list]`/`[/list]`、`[h2]`/`[/h2]`、`[url=...]`/`[/url]` 等）。
- [ ] 所有链接可访问（尤其是 GitHub 链接）。
- [ ] 物品名与 `物品清单.md` 完全一致。
- [ ] 「已知问题」与验证状态一致；**未验证的功能不得写成已完成**。
- [ ] 更新公告条目按时间倒序排列，最新在最上方。
- [ ] 无 HTML 标签（Steam 描述不支持 HTML）。
- [ ] 纯 Steam 商店页/创意工坊链接可裸贴，GitHub 链接必须用 `[url=...]`。

### 5. 发布后

- 把这次的简介改动同步回 `Universal tool\文档\更新公告.md`，保持简介与公告一致。
- 若发现简介、物品清单与当前数据表不一致，以当前源码和 xlsx 为准，并在下一次公告中修正。

## BBCode 标签速查表

| 标签 | 作用 | 可粘贴示例 |
|---|---|---|
| `[h1]...[/h1]` | 一级标题 | `[h1]Universal Tool · 万能工具[/h1]` |
| `[h2]...[/h2]` | 二级标题 | `[h2]主要内容[/h2]` |
| `[h3]...[/h3]` | 三级标题（版本条目用） | `[h3]2026-08-29 · 标题[/h3]` |
| `[b]...[/b]` | 粗体 | `[b]Universal Tool[/b] 是一个综合模组。` |
| `[i]...[/i]` | 斜体 | `[i]仍在完善[/i]` |
| `[u]...[/u]` | 下划线 | `[u]重点[/u]` |
| `[strike]...[/strike]` | 删除线 | `[strike]已移除[/strike]` |
| `[spoiler]...[/spoiler]` | 剧透折叠 | `[spoiler]隐藏内容[/spoiler]` |
| `[list][*]...[/list]` | 无序列表 | `[list][*]条目一[*]条目二[/list]` |
| `[olist][*]...[/olist]` | 有序列表 | `[olist][*]第一步[*]第二步[/olist]` |
| `[hr][/hr]` | 分隔线 | `[hr][/hr]` |
| `[url=地址]文字[/url]` | 链接 | `[url=https://github.com/Tomori77/Universal-tool]GitHub 源码[/url]` |
| `[quote=作者]...[/quote]` | 引用 | `[quote=玩家]反馈内容[/quote]` |
| `[code]...[/code]` | 代码块 | `[code]Package id: Charlotte.UniversalTool[/code]` |
| `[img]图片URL[/img]` | 图片 | `[img]https://example.com/pic.png[/img]` |

注意事项：

- Steam 描述**不支持 HTML**，不要写 `<b>`、`<br>` 之类。
- 直接粘贴 Steam 商店页或创意工坊物品的**纯链接**，会自动渲染成预览卡片。
- GitHub 链接**必须**写成 `[url=...]显示文字[/url]`，否则不是可点击链接。

## 更新公告条目模板

单条版本公告的格式，直接追加到「更新公告」区最上方：

```text
[h3]2026-08-29 · 自动设备运行机制与万能肥料修复[/h3]
[list]
[*]【新增】万能肥料改为将作物推进至实际可收获的阶段。
[*]【修改】自动凝华器、自动复制机和自动熔炉开机后每小时消耗万能催化剂×1。
[*]【移除】移除 UT_便携魔法炮。
[/list]
```

填写规则：

- 每条公告只写**新增 / 修改 / 移除**三类，与 `更新公告.md` 的表述保持一致。
- 公告只记录**玩家可见**的变化，不写入开发过程、反编译结论和待决策事项。
- **不写入未验证内容为已完成**；验证状态尚未确认的功能，放到「已知问题」区说明。
