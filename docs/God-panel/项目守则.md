# 天神面板 · 项目守则（God-panel）

> 本文件是 God-panel 的**唯一权威工作守则**。任何 agent（主对话或子 agent）在本项目工作前必须完整阅读。
> 目的：**用文档换上下文**——把稳定知识固化在此，减少每次对话的重复输入与探索。
> 正文位于 `docs/God-panel/`；工程根 `God-panel/AGENTS.md` 只是指向本文件的指针，以便会话自动加载。
> 易变信息（版本、验证状态、待办）不写在本文件，统一见 `docs/God-panel/项目状态.md`。
> 修改本守则须显式说明理由。

---

## 0. 一句话定位

`God-panel`（天神面板）是一个《口袋修仙》**游戏内受限调试面板**：挂载官方角色总览页与游历页入口，查看状态、发放灵石、按图鉴分类浏览/搜索并发放全部官方可获取道具。
工程目录 `D:\1orca\KDXXmod\God-panel`，文档目录 `D:\1orca\KDXXmod\docs\God-panel`。

---

## 1. 强制工作流

1. **子 agent 优先**：可拆分的工作（探索、代码、数据、文档）必须通过 `Task` 工具派发，不在主对话逐步做。
2. **主对话工作需申请**：确需在主对话直接改动，先说明「为何不能派子 agent」并取得同意。
3. **派发规范**：提示词含目标、涉及文件（绝对路径）、须遵守的守则章节、验收标准、需返回的信息；子 agent 只做被分配的一件事，不顺手重构。
4. **先读后写**：改任何文件前先读它及相邻文件。
5. **验证门禁**：任何代码改动收尾必须跑 `./tools/validate.ps1`（退出码 0）。
6. **不猜测**：游戏字段/机制一律以 SDK 快照为准，不凭记忆编造。
7. **禁止擅自提交**：不 `git commit`/`push`，除非用户明确要求。

## 4. 硬约束与红线

**能力边界（SDK 实测，勿越界）**

- 入口为 `ui.entry: "surfaces"`，挂载官方角色总览页（`actions`）与游历页（`footer`）；不新增玩家可达地图。
- 灵石 `spiritStones` 单次 ±1,000,000。
- 发道具 `giveItem`：仅官方 `isPublished && isObtainable` 或同包道具；`count` 1–32；每次事务 `effects` ≤16 条、道具合计 ≤32 件。
- `world` 只读：不能改数值/境界/属性，不能伪造战斗。
- 无任意 HTML/CSS/DOM/网络/DLL；无热加载，须完全重启。
- 带脚本的包属 `ruleset`，绑定存档指纹；存档均为 `modded`。

**实现硬性要求**

- `modApiVersion: 2`；0.1.19 起 `surfaces` 入口仅需 `scripts` 域、无需 `maps`（旧 `node`/`menu` 入口才要求同包 `maps` 锚点，否则报 `SCRIPTS_REQUIRES_API_V2_AND_MAPS`）。
- `select.choices[].value` 与 `initial` 必须以字母开头（如 `i300001`）。
- `event.values` 以**控件 `id`** 为键，不是标签。
- 限额：每文档 ≤128 控件、≤8 层、≤32 表单字段；输出 ≤64 KiB；代码 ≤256 KiB；每包/会话 ≤16 脚本定义；`panel.options` ≤6。
- `queryItemIds`（≤32）仅加载期声明，声明非公开 ID 会让整包被拒；运行时不对 `giveItem` 做白名单。
- 脚本必须**同步**返回普通 JSON：无 `async`、无 `import/require`、无 `fetch`、无 `Date`。

**红线**

- 禁止修改 `docs/Reference/**`（SDK 只读快照）。
- 禁止编造游戏字段/枚举/机制。
- 禁止擅自 `git commit`/`push`。
- 包内只允许游戏可读内容，禁止写入文档/工具/报告/缓存。

## 5. 更新流程

1. 改代码（`panel.js` / `panel.json` / `manifest.json` 等）；需要发版时提升 `manifest.json` 的 `version`。
2. `./tools/validate.ps1` → 退出码 0（否则不继续）。
3. `./tools/deploy.ps1` → 本地部署测试（需完全重启游戏）。
4. `./tools/publish.ps1` → 上传创意工坊；`publishedfileid` 保持不变以覆盖同一作品。
5. 按 `docs/God-panel/更新简介.md` 同步 `创意工坊介绍.md` 的「更新公告」区与 `workshop.vdf` 的 `changenote`。
6. 更新 `docs/God-panel/项目状态.md`。

> 工具需 **PowerShell 7（pwsh）**；5.1 下调用会自动改用 pwsh。所有 JSON 以 UTF-8 读写。
